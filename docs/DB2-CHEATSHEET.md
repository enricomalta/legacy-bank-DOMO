# DB2 — mapa rápido

Conceitos: tabela, chave primária, chave estrangeira, SQL, host variable, SQLCA, SQLCODE, COMMIT, ROLLBACK e cursor.

No estudo inicial: SQLCODE 0 indica sucesso; 100 é a condição clássica de nenhuma linha encontrada; códigos negativos normalmente indicam erro. Consulte a documentação da versão do Db2 usada no ambiente real para detalhes.
