# CICS — mapa rápido

CICS é um gerenciador de transações utilizado para executar aplicações transacionais.

Comandos para reconhecer:

- EXEC CICS RECEIVE
- EXEC CICS SEND
- EXEC CICS LINK
- EXEC CICS XCTL
- EXEC CICS RETURN

LINK chama outro programa e aguarda retorno; XCTL transfere o controle para outro programa. COMMAREA é uma forma tradicional de comunicação de dados entre programas CICS.
